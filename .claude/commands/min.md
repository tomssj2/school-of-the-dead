Undo `/max` in the running School of the Dead game.

1. Make sure the game is open in the browser pane (preview server `school-of-the-dead`).
2. Run `window.schoolDev.min()` in the page with the javascript tool. It restores the game from just before `/max`, or starts a fresh default game if the page was reloaded since (the returned message says which). Don't edit any code for this.
3. Take a screenshot of the Lobby and reply in one line with which of the two happened.
